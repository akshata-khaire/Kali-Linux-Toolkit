# *50 Commonly Used Linux Commands*
1. `ls` - List files and directories.
2. `cd` - Change directory.
3. `pwd` - Print the current working directory.
4. `mkdir` - Create a new directory.
5. `rmdir` - Remove an empty directory.
6. `touch` - Create a new empty file.
7. `cp` - Copy files and directories.
8. `mv` - Move or rename files and directories.
9. `rm` - Remove files and directories.
10. `cat` - Display the contents of a file.
11. `less` - View a file one screen at a time.
12. `head` - Display the beginning of a file.
13. `tail` - Display the end of a file.
14. `echo` - Display text in the terminal.
15. `clear` - Clear the terminal screen.
16. `history` - Display previously executed commands.
17. `man` - Display the manual for a command.
18. whoami` - Display the current username.
19. `who` - Display users currently logged in.
20. `date` - Display the current date and time.
21. `cal` - Display a calendar.
22. `uname` - Display system information.
23. `hostname` - Display the system hostname.
24. `id` - Display user and group information.
25. `which` - Show the location of a command.
26. `find` - Search for files and directories.
27. `grep` - Search for text inside files.
28. `sort` - Sort lines of text.
29. `uniq` - Display or remove repeated lines.
30. `wc` - Count lines, words, and characters.
31. `cut` - Extract sections from lines of text.
32. `diff` - Compare two files.
33. `file` - Determine the type of a file.
34. `stat` - Display detailed information about a file.
35. `du` - Show disk usage of files and directories.
36. `df` - Show available disk space.
37. `free` - Display memory usage.
38. `ps` - Display running processes.
39. `top` - Monitor running processes.
40. `kill` - Terminate a running process.
41. `sleep` - Pause for a specified amount of time.
42. `alias` - Create shortcuts for commands.
43. `unalias` - Remove command shortcuts.
44. `passwd` - Change a user's password.
45. `sudo` - Run a command with elevated privileges.
46. `su` - Switch to another user.
47. `exit` - Exit the current shell session.
48. `tar` - Create or extract archive files.
49. `gzip` - Compress files.
50. `gunzip` - Decompress gzip files.

*This collection of 50 Linux commands provides a practical foundation for navigating and working with the Linux command line. Understanding these commands can improve efficiency and build confidence when performing common tasks in a Linux environment.*
