# *A Collection of 100 Kali Linux Commands, Organized By Category for Learning and Authorized Security Testing*
### Reconnaissance & Information Gathering
1. `nmap` - Discover hosts, ports, and services on a network.
2. `masscan` - Perform high-speed port scanning.
3. `whois` - Retrieve domain registration information.
4. `dig` - Perform DNS lookups.
5. `host` - Perform DNS lookups for hosts and domains.
6. `nslookup` - Query DNS information.
7. `dnsrecon` - Perform DNS reconnaissance.
8. `dnsenum` - Gather DNS information about domains.
9. `fierce` - Perform DNS reconnaissance and identify potential targets.
10. `theHarvester` - Gather publicly available information about domains.
11. `recon-ng` - Perform web-based reconnaissance.
12. `spiderfoot` - Automate open-source intelligence gathering.
13. `amass` - Discover and map network assets and subdomains.
14. `subfinder` - Discover subdomains using passive sources.
15. `whatweb` - Identify technologies used by websites.
 ### Network Scanning & Analysis
16. `ping` - Test network connectivity.
17. `traceroute` - Trace the network path to a destination.
18. `arp-scan` - Discover devices on a local network.
19. `netdiscover` - Discover hosts on a local network.
20. `ss` - Display network connections and listening ports.
21. `tcpdump` - Capture and inspect network packets.
22. `tshark` - Analyze network traffic from the command line.
23. `wireshark` - Capture and analyze network traffic.
24. `netcat` - Read and write data across network connections.
25. `socat` - Create and relay connections between different endpoints.
26. `hping3` - Craft and send customized network packets.
27. `ncat` - Perform network connections and data transfers.
28. `arp` - Display or manage the ARP cache.
29. `ip` - Display and manage network interfaces and routes.
30. `route` - Display or modify network routing information.
